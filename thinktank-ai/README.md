# ThinkTank AI

**Learn by thinking, not just by getting answers.**

A hackathon prototype for the problem statement: *"Build autonomous AI learning peers that
collaborate with students to solve problems and enhance critical thinking."*

ThinkTank AI puts a student in a small study group of five distinct Gemini-powered AI
personas — **Explorer, Challenger, Critic, Mentor, Devil's Advocate** — orchestrated so the
student reasons their way to an answer instead of being handed one.

---

## Quick start

```bash
npm install
cp .env.example .env.local
# edit .env.local and paste a key from https://aistudio.google.com/apikey
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**No API key yet?** The app still runs. Every AI action has a graceful, clearly-labeled mock
fallback (`src/lib/mock.ts`) so the full UI and flow can be demoed offline. Add
`GEMINI_API_KEY` any time to switch to live Gemini responses — no code changes needed.

## Architecture

```
Student
  │
  ▼
Next.js Frontend (React, client components)
  │  fetch("/api/ai", { action, payload })
  ▼
/api/ai  (Next.js route handler — server only)
  │
  ├─ Orchestrator (src/lib/orchestrator.ts)
  │    decides: which peer responds, hint level, misconception flag,
  │    whether to nudge toward a No-AI Round
  │
  ├─ Peer persona prompts (src/lib/prompts.ts)
  │    Explorer / Challenger / Critic / Mentor / Devil's Advocate —
  │    each a distinct system instruction, never a generic prompt
  │
  ▼
Gemini service (src/lib/gemini.ts) → @google/genai → Gemini API
  │
  ▼
AI Peer Response → JSON → Frontend renders it in that peer's voice/color
```

`GEMINI_API_KEY` is read only in `src/lib/gemini.ts`, which runs exclusively on the server
(`export const runtime = "nodejs"` in the API route). The browser never sees the key — it only
ever talks to `/api/ai`.

### Why the peer *selection* is a rule-based state machine

For a reliable live demo, `decide()` in `src/lib/orchestrator.ts` picks the next peer with a
small, fast, deterministic state machine (Explorer → Challenger → Critic → Mentor rhythm,
with instant Mentor hand-off if the student signals they're stuck). The *content* of every
reply is still 100% generated by Gemini using that peer's persona and the live conversation.
This keeps the demo reproducible on stage. Swapping the state machine for an LLM-driven router
(have Gemini itself choose the next peer from a JSON schema) is a natural next step — the
function signature already accepts everything an LLM router would need (history, usage stats,
prior mistakes, mode).

## Feature map

| Feature | Where |
|---|---|
| AI Peer Team | `src/components/PeerTeam.tsx` |
| Collaborative Learning Session (Explorer → Challenger → Critic → Mentor) | `src/components/LearningSession.tsx` |
| Mistake Analysis (gentle, structured) | `LearningSession.tsx` → `POST /api/ai { action: "mistake_analysis" }` |
| Mistake Museum (persistent via localStorage) | `src/components/MistakeMuseum.tsx`, `src/lib/storage.ts` |
| AI Debate (two Gemini-generated viewpoints, reasoning-graded) | `src/components/DebateMode.tsx` |
| Teach the AI (role reversal, Gemini asks follow-ups) | `src/components/TeachTheAI.tsx` |
| No-AI Round | `src/components/NoAIRound.tsx` |
| AI Dependency Detector + Critical Thinking Score | `src/components/GrowthDashboard.tsx` |
| Explain It My Way (simple / example / meme / story / cinema / Tanglish) | `src/components/ExplainMyWay.tsx` |

All local, session-scoped state (mistakes, usage stats, thinking score) lives in
`src/lib/storage.ts` using `localStorage` — enough to demo persistence without a database.

## Tech stack

- Next.js 14 (App Router) + React 18 + TypeScript
- Tailwind CSS, Lucide React icons
- `@google/genai` (Gemini's current official JS SDK) via a server-only API route

## Extending

- Swap the rule-based orchestrator for an LLM router: add a `generateJSON` call in
  `decide()`'s call site that asks Gemini to pick the peer + flags from the same inputs.
- Swap `localStorage` in `src/lib/storage.ts` for a real database — the read/write functions
  are already the only integration surface.
- Add streaming: `ai.models.generateContentStream` is a drop-in swap for
  `generateContent` in `src/lib/gemini.ts`.
